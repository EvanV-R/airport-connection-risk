# Agent Instructions

## Project
Airport Connection Weather Risk Calculator

## Development Rules
- Use plain HTML, CSS, and JavaScript.
- Use the simplest code that works.
- Do not add features I did not request.
- Follow the requirements in PRD.md.
- Follow the design direction in DESIGN.md.
- Use the Open-Meteo API for weather forecasts.
- Use fetch() and async/await for API requests.
- Put every fetch request inside try/catch.
- Check response.ok before reading API data.
- Handle all five UI states: empty, loading, error, invalid input, and in use.
- Do not use React, Tailwind, frameworks, libraries, or CDNs.
- Do not include API keys in the repository.
- Keep the code readable and easy to explain.
- Make the website mobile-friendly.
- Use semantic HTML and accessible form labels.
